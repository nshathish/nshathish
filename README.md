## 📐 Architecture & Patterns

- **Microservices** — loosely coupled services with independent deployments
- **Modular Monolith** — structured monoliths with clear module boundaries
- **CQRS** — command/query responsibility segregation with FastAPI & .NET
- **Clean Architecture** — dependency-inversion-driven layered design
- **Infrastructure as Code** — Azure Bicep & AWS CloudFormation
- **Event-Driven Architecture** — Azure Service Bus, IoT Hub and Azure Functions for real-time, decoupled data flows
- **Durable Orchestration** — stateful, long-running workflows with Azure Durable Functions
- **System Interoperability** — integrating CRM platforms, Guidewire policy administration (via Mule) and IoT telemetry
- **API Gateway Design** — centralised policies, throttling and versioning with Azure API Management
- **Monolith-to-Microservices Migration** — incremental decomposition of large legacy systems
- **Observability** — Azure Monitor & Application Insights across .NET estates
- **Secure by Design** — Key Vault secrets management, Entra ID RBAC, PCI-compliant payment flows
